[![InfraGPT](https://github-readme-stats.vercel.app/api/pin/?username=Aashish-Chandr&repo=InfraGPT&theme=tokyonight&hide_border=true&show_icons=true)](https://github.com/Aashish-Chandr/InfraGPT)

</div>

> **The crown jewel.** A production-grade platform where AI watches your Kubernetes cluster 24/7 — predicting anomalies before they happen, healing failures automatically, and explaining everything in plain English.

```
Stack: Python · TypeScript · Terraform · kopf Operator · ArgoCD · Prometheus
       Grafana · Loki · Jaeger · HashiCorp Vault · Kyverno · React · FastAPI
```

| Module | What it does |
|---|---|
| 🤖 **AI Engine** | Facebook Prophet + Isolation Forest trained on 30d of Prometheus metrics |
| 🧠 **LLM RCA** | GPT-4 / Claude explains root causes in plain English with deployment correlation |
| ☸️ **kopf Operator** | Watches HealingPolicy CRDs → auto-rollback, restart, scale, notify |
| 🔄 **GitOps** | ArgoCD ApplicationSet → every Git push is a deployment |
| 🔐 **Zero Secrets in Git** | All secrets flow through HashiCorp Vault with K8s auth |
| 📊 **Full Observability** | Metrics (Prometheus/Grafana) + Logs (Loki) + Traces (Jaeger) |
| 💰 **Cost Optimizer** | Detects over-provisioned pods and estimates monthly AWS savings |
| 🔥 **Chaos Mode** | Intentionally breaks things to prove self-healing works |

**📉 MTTR: 15 minutes → 90 seconds** &nbsp;|&nbsp; **🎯 Auto-Heal Success Rate: ~87%**
